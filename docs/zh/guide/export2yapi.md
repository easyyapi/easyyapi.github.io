# 导出到 YApi

## 使用方法

### 方式一：右键导出

1. 打开项目中包含 API 的文件，或者在 IDEA 左边项目文件区域选择文件或文件夹
2. 鼠标右键点击文件内容或文件夹
3. 选择 `ExportYapi` 导出该文件或文件夹中所有的 API

### 方式二：快捷键导出

1. 打开项目中包含 API 的文件，或者在 IDEA 左边项目文件区域选择文件或文件夹
2. 使用快捷键 `Alt + Shift + E` (Windows/Linux) 或 `Ctrl + E` (macOS)
3. 选择要导出的 API，选择导出渠道 `YApi`
4. 点击 ✔ 按钮或按回车键完成导出

## 错误信息

当 YApi 服务器拒绝请求时——token 无效或过期、项目不存在、权限不足——失败通知会带上服务器自己的拒绝原因，而不是一句通用报错，便于直接定位需要修改的设置。自 v3.2.6 起，服务器响应字段缺失（例如分类条目的 id 为 JSON `null`）也不再导致导出失败：不可用的条目会被跳过，其余内容正常写入。
